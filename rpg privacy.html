RPG application privacy

Who we are

RPG is an offline tabletop role-playing companion: character sheets, reusable classes ("backstage"), monster sheets, and dice rolling. It is published by Nicolas Oudard (nicolas@oudard.org).

About the application

You can install it from the Google Play Store. The app does not require access to location, contacts, the camera, the microphone, or the advertising ID. It does not use the Internet to run; network access is only involved when you install or update the app through the store.

User Data

The RPG application does not collect any personal data. There is no user account, no advertising, no analytics, and no telemetry.

Your parties, character sheets, monster sheets, and backstage classes are saved only on your device using the system's local storage. Nothing is sent to a server, cloud service, or third party. Uninstalling the app removes this data.

Permissions and APIs that Access Sensitive Information

The RPG application does not use APIs that access sensitive information and does not request sensitive permissions.

Device and Network Abuse

The RPG application does not use the network during normal use except as part of installation or updates via the store, and it does not alter device integrity.

Deceptive Behavior

The RPG application does not require changing device settings and does not modify anything on the user's device beyond storing game data locally for the app itself.

Misrepresentation

Not applicable
